# Learning Record - Example track

Append-only. One entry per lesson unit, newest at the bottom. A correction is a new entry that names the one it supersedes. Start a continuation note when this one gets long.

## Entry template

### YYYY-MM-DD - EX-1.1 Lesson name

- **Session goal:** as the learner stated it
- **Stated time and new material:** as the learner stated them
- **Source material:** what the lesson was drawn from
- **Exercise:** what the learner did
- **Result:** what happened, with evidence
- **Test:** first-try score (for example 6 of 7, 86%) and the missed questions
- **Lesson:** what is now known, in one or two sentences
- **Practical task:** the project and the change; evidence read (output, diff or file), or `not checked`
- **Status:** passed | in progress | placed out | skipped by learner
- **Next application:** where it is used next on a project
